# Color Pop Adventure

Versione Android offline del gioco Color Pop Adventure.

## Generare l'APK con GitHub

1. Crea un repository GitHub vuoto.
2. Carica tutti i file e le cartelle di questo progetto nel repository.
3. Apri la scheda **Actions**.
4. Se richiesto, abilita GitHub Actions.
5. Apri **Build Color Pop APK** e premi **Run workflow**.
6. Al termine, apri l'esecuzione completata.
7. Nella sezione **Artifacts**, scarica **ColorPopAdventure-APK**.
8. Estrai il file ZIP: dentro troverai `ColorPopAdventure.apk`.

L'APK generato è una build di prova firmata automaticamente da Android.
Può essere installata manualmente su un telefono Android autorizzando
l'installazione da quella specifica fonte.

## Dati tecnici

- Application ID: `com.colorpop.adventure`
- Versione: `0.2`
- Android minimo: 7.0 (API 24)
- Target Android: API 35
- Il gioco funziona offline
- Progressi e stelle vengono salvati localmente sul telefono
