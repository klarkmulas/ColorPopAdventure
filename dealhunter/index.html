🔌 Collega eBay LIVE

Per mostrare annunci reali DealHunter usa la Browse API ufficiale eBay. Incolla qui un Application Access Token temporaneo. Non inserire mai Client Secret / Cert ID. Il token non viene salvato in localStorage né nel repository: resta solo nella memoria della pagina e sparisce al refresh.

Se il browser aziendale blocca le richieste API cross-origin, DealHunter te lo segnalerà: in quel caso servirà un piccolo backend/proxy sicuro. La ricerca eBay diretta continuerà comunque a funzionare.
